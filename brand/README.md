**Brand line:** Cache locally. Sync everywhere.

| --- | --- | --- |

Avoid the previous orange-red/teal branding in new artwork. Keep old JPEG and PNG assets as legacy files. The diagrams illustrate cache synchronization, not database replication or full Redis command parity.
