## 1. What the AOF holds now

A primary begins every new or emptied file with `FORMAT(expirylog, txn)` (id `17005593296757653505`, 57 bytes). In such a file an `EXEC` that logs two or more records writes:

```
*2 RECACHED-CHECKPOINT 17005734034245943298     TXN-BEGIN 2 (kind 0x81, payload 2)
*3 SET acct:a new                                the 6O-G batch, unchanged:
*3 SET acct:b new                                expiry DEL, frame, eviction DELs per command
*2 RECACHED-CHECKPOINT 17005735133757571074     TXN-COMMIT 2 (kind 0x82, payload 2)
```

| `EXEC` produced | Written |
|---|---|
| nothing (read-only, `PUBLISH`-only, nothing effective) | nothing |
| one record | the record alone |
| two or more | one group, in the same batch and `write(2)` as before |

Groups are written only while the file is a `txn` file (`Timeless` and `grouped`). A legacy file, or a 6O-H file (`FORMAT(expirylog)`), gets none until its next checkpoint, whose truncation batch writes `FORMAT(expirylog, txn)`. Test `only_a_txn_file_gets_groups_until_its_checkpoint`.

## 2. The writer

| Path | How a transaction is queued |
|---|---|
| Inline (`append_transaction`) | `group_markers` builds `TXN-BEGIN n`/`TXN-COMMIT n` and checks each member is one record **before** the queue lock (review B F4); `push_batch` pushes markers and members in one lock hold iff the batch's file groups |
| Coalesced (`append_coalesced_transaction`) | the same, then the 6N-C4 yield/lead protocol, unchanged |
| Deferred TCP (`append_client_transaction`) | the same, queued under the caller's stripes; the connection waits once before its reply, unchanged |

A member that is not exactly one record (impossible with `broadcast_for_at`'s frames), or more than `u32::MAX` members, writes the batch ungrouped with an error log, rather than a group the replay would refuse (review A L6).

**A failed `write(2)`** (`cut_back`): `whole_frames_len` keeps whole frames only outside a group whose `TXN-COMMIT` did not land, so the file never ends inside a group the next append would follow. A failed cut is retried before the next write (`torn_at`); an unknown position stops appends until a truncation (pre-existing; see L3 in the release gate). Tests at every boundary: `a_failed_write_inside_a_group_is_cut_back_to_its_begin`; unit `a_cut_never_keeps_part_of_a_transaction_group`. Review B tore a batch of group + single + group at every one of its 642 byte offsets (`raw/i2-review/`): no group was ever part-present.

## 3. Replay

Pass 1 classifies every group in the timeless part of a `txn` file (design §3.1; the rows in order, authorship first):

| Found | Result | Test |
|---|---|---|
| complete group | replayed, markers skipped | `a_complete_group_replays_and_its_markers_are_skipped` |
| incomplete group at the tail (arrays only from its `TXN-BEGIN`; begin alone, members, all but `COMMIT`, a torn `COMMIT`) | **none of it applied**; its bytes copied to `<aof>.cut-<offset>-<ms>` (temporary name, renamed after `sync_all`, best effort), then the file is cut back to `TXN-BEGIN` | `an_incomplete_tail_is_discarded_and_cut_back_to_its_begin`, `the_bytes_a_tail_cut_removes_are_kept_beside_the_file`, `a_tail_cut_whose_copy_cannot_be_written_still_starts` |
| a push inside an open group (any kind: data, DEDUP, a checkpoint marker) | **abandoned**: members replayed one by one; the push handled as 6O-H handles it | `a_group_another_server_appended_after_replays_one_by_one`, `any_push_inside_an_open_group_abandons_it_first`, `the_files_older_binaries_left_replay_here` (six real T4 files) |
| a non-ignorable unknown control inside a group | abandoned | `later_writers_control_kinds_follow_the_6oh_rules_inside_groups` |
| an ignorable unknown kind, or `FORMAT` not at the head, inside a group | skipped, not a member | same |
| nested `TXN-BEGIN`; a stray or mismatched `TXN-COMMIT`; more members than declared; a group of one; an array checkpoint or a DEDUP record inside | **refuses the start** | `malformed_groups_refuse_the_start` (9 cases) |
| a record holding a nested record, at or after the replay start | refuses the start (D4) | same; `a_nested_record_before_the_replay_start_does_not_refuse_it` |
| group markers after the timeless part, or in a non-`txn` file | ignorable no-ops (6O-H) | `group_records_outside_a_txn_file_are_ignorable_no_ops` |
| a member flipped from `*` to `>` | abandoned; nothing lost; the rest of the file legacy until the next checkpoint | `a_member_flipped_to_a_push_abandons_its_group_and_loses_nothing` |

Pass 2 applies records up to the incomplete tail, if any. The file is already read whole (pre-existing), so classification costs a few integers of state and no buffering.

## 4. The reproduction

`an_exec_cut_anywhere_in_its_records_replays_all_or_nothing`: the baseline's 34-of-68 reproduction (`V0.6O-I-BASELINE.md` §1.1), extended with an expiry `DEL` inside the transaction, cut at **every** byte from the transaction's first record to its end, each cut booted, written to, and booted again. On `dev` `0a1f95e`: every cut replays all of it (only the uncut file) or none of it, every incomplete one is cut back to the records before it, and the next session's write survives the next restart.

## 5. Observability

| Metric | Meaning |
|---|---|
| `recached_aof_incomplete_transactions_total` | incomplete tail groups discarded at startup |
| `recached_aof_abandoned_transactions_total` | groups another server appended after |
| `recached_aof_tail_cuts_total{kept="true"\|"unsynced"\|"false"}` | every tail cut, with whether its copy was kept |
| `recached_aof_tail_cut_bytes_total` | bytes cut |

`.cut-` files are never removed by the server: one per startup that cut a tail; the operator inspects and removes them.

## 6. Mutants

From `raw/mutation/` (25 mutants over PR 2–PR 5, run on `055cfba` with the PR test filters): every AOF mutant is killed: omit `TXN-BEGIN` (M1), omit `TXN-COMMIT` (M2), apply an incomplete tail (M3), lose the expiry `DEL` (M11) or the eviction `DEL`s (M12), accept a nested group (M15), keep part of a group on a failed write (A1), no abandonment on a push (A2), accept nested records (A3), `FORMAT` without `txn` (A4), groups in non-`txn` files (A5), a group of one (A6).

## 7. Limits

- Framing detects truncation, not corruption: a length corrupted mid-file still looks like a torn tail (pre-existing), now cut with a copy kept.
- An upgraded legacy or 6O-H file gains framing at its first checkpoint (autosave every 900 s by default, or `SAVE`); with autosave off and crash-only restarts, never.
- `fsync` policies are unchanged: framing makes a lost transaction lost whole; it does not make an `everysec` transaction durable (`V0.6O-I-CRASH-RECOVERY.md` §3).
