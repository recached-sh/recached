## 1. Negotiation

| Direction | String |
|---|---|
| primary advertises | `<run-id>;caps=dedup1,expirylog1,txn1` (`;caps=expirylog1,txn1` with DEDUP replication off) |
| replica answers | `<resume-id>;accept=dedup1,expirylog1,txn1` |

Never inferred from a version. 68 of the 128 bytes every release accepts, with a 40-character run id. Older replicas split the list on `,` and look for their own tokens: verified with real binaries (`raw/i6-compat/repl-compat.txt`: 6O-H, 6O-G, 6O-F and v0.5.2 replicas of a 6O-I primary link, follow and converge; a 6O-H or v0.5.2 primary's 6O-I replica too).

The four combinations (`every_combination_of_expirylog1_and_txn1_converges`):

| `expirylog1` | `txn1` | Result |
|---|---|---|
| no | no | legacy stream, converges |
| yes | no | logged expirations, frames one by one, converges |
| no | yes | groups applied atomically at one instant, converges |
| yes | yes | groups applied atomically and timelessly, converges |

## 2. The wire

Unchanged frames (`offset u64 LE`, `len u32 LE`, bytes). Before a group's first frame, a link that accepted `txn1` gets:

```
offset = 0  |  len = 24  |  1 (version) 1 (GROUP) 0 0  |  count u32  |  first u64  |  bytes u64
```

`a_capable_replica_gets_a_header_before_each_group_and_an_older_one_none` checks these bytes exactly, and that an older replica's link (no `txn1`) gets the same frames with no header. A single write gets no header. No `FORMAT` or `TXN-*` AOF record ever goes on the wire; every frame stays a push.

## 3. The primary

`fan_out_group` holds the stream lock once per transaction: offsets advance by `count` in one `fetch_add`, the frames are backlogged with their extent (`ReplGroup { first, count, bytes }` on every frame), and each replica's queue gets them in order. `a_groups_offsets_are_consecutive_among_concurrent_writers`: 4 connections × 50 rounds of single writes and 3-frame `EXEC`s: all 100 groups at consecutive offsets.

## 4. The replica's assembler

At most one open group per link. Every violation is `InvalidData`, which ends the link, clears the resume point (`run_repl_client`) and forces a full sync (`malformed_groups_force_a_full_synchronization`, 10 cases):

| Rule | Case |
|---|---|
| header length, version, kind, reserved bytes | "an unknown header version" |
| `count ≥ 2` | "a group of one" |
| `count ≤ 524,288` | "a group of more frames than the bound" |
| `bytes + 128 × count ≤ 64 MiB` (from the header, before buffering) | "a group past the bound" |
| `first` = committed + 1 | "a header for another offset" |
| no header inside an open group | "a header inside a group" |
| consecutive member offsets | "a member at the wrong offset" |
| members' bytes = header's bytes | "longer" / "shorter than declared" |
| no DEDUP member | "a DEDUP record inside" |
| offsets past `u64::MAX` (review D, D-2) | `offsets_past_u64_max_are_a_protocol_error` |
| a header on a link without `txn1` | `a_header_on_a_link_without_txn1_is_a_gap` (today's gap error) |

Nothing of a group is applied or acknowledged before its last member: a link that ends inside it resumes before it (`a_link_that_ends_inside_a_group_applies_none_of_it_and_resumes_before_it`, a fake primary that drops the link after the header and one member, then resumes with a partial sync carrying the whole group).

`ReplResume` remembers `txn1` as it remembers `expirylog1`: a resume point taken from a per-frame stream is never offered to the same run id when it offers `txn1` (`a_resume_point_is_offered_only_in_the_framing_mode_it_was_taken_in`, which kills mutant M10).

## 5. Mutants

Killed: headers to a replica that did not accept `txn1` (M9), the backlog losing group extents (M7), a group applied before its last member (M4), the resume point advanced before the group commits (M6), the group bound skipped (M16), framing mode ignored on resume (M10, by the test added after the first run). M17 (a second header replacing an open group) is **equivalent**: the header's `first` must equal the open group's next offset, so the next data frame always fails the offset check and forces the same full sync.
