## Starting point (6O-B, measured, not re-derived)

No-persistence, 1 worker, 50 clients, P=1, against Redis 7.2.5 (`../6o-b/V0.6O-B-RELEASE-GATE.md`):

| Command | Ratio | Target |
|---|---:|---:|
| SET | 0.925× | ≥ 0.90× (met) |
| LPUSH | 0.896–0.897× | ≥ 0.90× |
| SADD | 0.870× | ≥ 0.90× |
| MSET ×10 | 0.829–0.844× | ≥ 0.90× |

Open conditions carried into 6O-C:
- **B3**: the P=16 tail after reply coalescing. MSET P=16 p99 4.21 → 4.66 ms at 1 worker; SET P=16 p99 0.94 → 1.18 ms at 3 workers; +3% CPU per op for one client at 3 workers.
- **The WATCH overflow High**: a pre-existing bug, and a release blocker.

The 6O-A/6O-B AOF, ordering and durability invariants this phase must keep:
- no reply before its AOF write;
- the gate's coalescer unchanged;
- AOF-before-fan-out;
- `RECACHED_AOF_FANOUT=inline` as the default;
- DEDUP ack order;
- fail-stop exit 74.
